履歴書の資格欄を前にして、「このTOEICスコア、書いていいのかな。逆に低く見られないかな」と手が止まる。転職活動あるあるだと思います。

一般的な目安は600点以上。ただし「何点だから書けない」という公式ルールは存在しません。応募する職種や求人要件によっては、600点未満でも書いたほうがいい場面があります。

僕は転職を4回経験し、大手企業では採用面接官として履歴書を見る側にも立ってきました。採用側に回って分かったのは、資格欄のTOEICで見られているのが点数だけではない、ということです。

## 目安は600点。その根拠はどこにあるのか

履歴書に書けるスコアに明確な基準はありません。それでも「600点以上が目安」と広く言われるのには、それなりの裏付けがあります。

| 根拠となるデータ | 数値 |
| --- | --- |
| TOEIC L&R 公開テストの全受験者平均スコア | 約615点（2024年度・IIBC「[TOEIC Program DATA & ANALYSIS 2025](https://www.iibc-global.org/toeic/official_data.html)」） |
| 英語を使う部署の中途採用でスコアを要件・参考にする企業の期待スコア平均 | 620点（IIBC「[英語活用実態調査](https://www.iibc-global.org/toeic/special/job/data.html)」） |

つまり600点は「受験者全体の平均に近く、企業が参考にするラインにも近い」水準。ここを超えていれば、少なくとも「英語が苦手な人」とは見られません。

採用側の感覚で言うと、600点は「お、勉強しているな」と思うラインで、減点材料になることはまずない。600点の難易度や必要な学習量については[TOEIC600点の難易度](/english/toeic-600ten)で詳しく解説しています。

### 期待されるスコアは、部署によって150点も違う

ただ、600点という数字を一律の合格ラインのように扱うのは乱暴です。同じIIBCの英語活用実態調査（2022）では、企業が社員に期待するスコアが部署ごとに整理されています。

| 部署 | 企業が期待するスコア（平均） |
| --- | --- |
| 技術部門 | 560点 |
| 営業部門 | 580点 |
| 海外部門 | 705点 |

技術部門と海外部門で145点の開き。ここが実務的に大事なところで、**あなたのスコアが高いか低いかは、応募先の部署が決めます**。550点は海外営業では足りず、国内の技術職なら十分に「期待値どおり」です。求人票に英語要件が書かれていないなら、560〜580点あたりが暗黙の基準だと考えて構いません。

もう一段上を目指すなら、700点が次の節目です。700点を超えると受験者の上位約3分の1に入り、海外部門の期待値にも届く。履歴書の一行としての存在感が変わります。

### スコア帯ごとの、現実的な扱い

面接官として履歴書を見ていたときの感覚を、点数帯で言語化するとこうなります。

| スコア帯 | 採用側から見た印象と、書くかどうかの判断 |
| --- | --- |
| 800点以上 | 英語が選考軸の求人でも通用する。職務経歴のどこで使ったかまで書きたい |
| 700〜795点 | 上位3分の1。英語を使う求人への応募が現実的になるライン |
| 600〜695点 | 平均超え。ほぼすべての求人で、書いてプラスにこそなれマイナスにはならない |
| 500〜595点 | 英語職以外なら書いてよい。取得年月が新しければ「学習中」の証明として機能する |
| 495点以下 | 英語要件のある求人では伏せる。それ以外は、直近のスコアなら書く価値がある |

495点以下でも一律に「書くな」とは思いません。判断を分けるのは点数そのものより、**応募先が英語力を評価軸に置いているかどうか**です。

## 履歴書への正しい書き方

基本は次の形です。

```
2025年10月　TOEIC Listening & Reading Test 650点取得
```

記載欄は「免許・資格」欄。職歴欄や自己PR欄に混ぜず、資格欄に置くのが原則です。

### 正式名称で書く

「TOEIC 650点」という略記ではなく、**「TOEIC Listening & Reading Test」と正式名称で書く**のが基本マナーです。TOEICにはL&R以外のテストもあるため、どのテストのスコアか明記する意味もあります。

細かいことのようですが、履歴書は「正確に書ける人かどうか」を見られる書類。資格の正式名称を調べて書ける人は、それだけで丁寧な印象になります。

### 取得年月を必ず入れる

取得年月のないスコアは、採用側からすると「いつの実力かわからない」状態です。年月が書いてあれば、最近の努力なのか、学生時代の遺産なのかが伝わる。ここに書くのは受験した試験日で、認定証が届いた日ではありません。

### 複数回受けているなら最高スコアでOK

TOEICは何度でも受験でき、履歴書にはベストスコアを書いて問題ありません。「最高点を書くのはずるいのでは」と気にする人がいますが、採用側もベストスコアである前提で見ています。そこは堂々と書いてください。

## L&R以外を受けた場合の書き方

ここで迷う人が多い割に、まとまった説明を見かけません。テストの種類ごとに整理します。

### TOEIC Speaking & Writing Tests

S&Wは各200点、合計400点満点です。990点満点のL&Rと混同されないよう、**分母まで書く**のが親切な書き方になります。

```
2025年10月　TOEIC Speaking & Writing Tests 280/400点取得
（Speaking 150点／Writing 130点）
```

内訳まで書くかは好みですが、話す力が求められる求人なら、Speaking単体のスコアが見えたほうが有利に働きます。

### TOEIC IPテスト

大学や勤務先で受けた団体受験がIPテストです。**履歴書に書いて問題ありません。**ただし公開テストとは運営形式が異なるため、IPであることを隠さず明記します。

```
2026年1月　TOEIC Listening & Reading IPテスト（オンライン） 700点取得
```

注意点がひとつ。企業によっては公開テストのスコアのみを認める運用があります。英語力が選考の主要な評価軸になる求人に応募するなら、公開テストを受け直しておくほうが確実です。逆に、英語が主要件でない求人でIPスコアが不利に働く場面は、まず見ません。

### TOEIC Bridge

初中級者向けの別テストで、L&Rとはスコアの尺度が違います。書いても構いませんが、L&Rのスコアを持っているならそちらを優先してください。両方書くと、かえって英語力の判断を迷わせます。

### やりがちなNG表記

面接官として履歴書を見ていて、惜しいなと感じた表記のパターンです。

| NG例 | 何が惜しいか |
| --- | --- |
| 「TOEIC 650点」とだけ書く | どのテストか不明。正式名称で書きたい |
| 取得年月の記載なし | いつの実力か判断できない |
| 「TOEIC 650点合格」と書く | TOEICに合否はない。「取得」が正しい |
| S&Wを「280点」とだけ書く | 400点満点が伝わらず、L&Rの280点と誤解される |
| 自己採点や模試のスコアを書く | 公式スコア以外は書かないのが原則 |

特に「合格」表記は意外と多いミスです。TOEICはスコア型のテストで、合格・不合格という概念がありません。小さな誤りですが、資格欄は正確さがそのまま印象になる場所。提出前に一度見直してみてください。

## まだ受験していない、勉強中の場合

取得していないスコアを資格欄に書くことはできません。ただ、受験予定なら書けます。

```
2026年11月　TOEIC Listening & Reading Test 受験予定
```

備考欄や自己PRで「現在730点を目標に学習中」と添える手もあります。黙っているより、学習を継続している事実を見せたほうがいい。面接官が資格欄から読み取ろうとしているのは完成された英語力だけではなく、**この人が今も伸びているかどうか**だからです。

働きながらスコアを伸ばす方法は[社会人のTOEIC勉強法](/english/toeic-benkyou-shakaijin)にまとめました。

## 低スコアでも書いたほうがいいケース

「600点未満だから書かない」と機械的に判断するのは、もったいないことがあります。求人要件が「TOEIC500点以上歓迎」なら、要件を満たすスコアは当然書くべきです。英語をほぼ使わない職種なら、スコアの絶対値より「社会人になっても学び続けている」姿勢の証明として機能します。

伸びている途中のスコアも同じ。直近の取得年月とあわせて書けば、現在進行形の努力として伝わります。面接で「今も勉強を続けていて、次回で更新を狙っています」と添えられれば、むしろプラス材料になる。

逆に書かないほうがいいのは、応募職種が高い英語力を前提としているのに、要件に大きく届かないスコアを書く場合くらいです。要件とのギャップが目立つときだけは慎重に、が僕の感覚です。

## スコアの有効期限と、古いスコアの見られ方

誤解が多いポイントです。

**TOEICスコアに公式な有効期限はありません。**一度取ったスコアが失効することはなく、何年前のものでも履歴書に書くこと自体は可能です。

ただし採用の現場では、2年以内のスコアが目安とされる場面が多い。公式認定証の再発行受付に期限がある関係などから、「スコアは2年以内のものを」と案内する企業もあります（運用は企業により異なります）。

面接官としての本音を言えば、10年前の800点より、半年前の650点のほうが信頼できます。英語力は使わなければ落ちるもの。古いスコアしかない人には「そのスコア、今も再現できますか」と内心で問いたくなるわけです。

学生時代のスコアしか手元にない人は、転職活動を機に受け直すことをおすすめします。スコア100点アップには一般に200〜300時間の学習が必要と言われますが（諸説あります）、現状維持の確認だけなら、思い出しのための学習でも十分戦えます。

### 証明書の提出を求められることはあるか

内定前後で公式認定証の提示を求められるケースはあります。頻度は高くありませんが、外資系や英語要件が明示された求人ではまれに発生する。認定証は手元に保管しておいてください。

裏を返せば、証明を求められて困るような書き方はしない、ということでもあります。

## 採用側が資格欄から読み取っている「スコア以外」のこと

資格欄のTOEICから読み取っているのは、実は点数だけではありません。取得年月から見える学習の継続性。正式名称や表記の正確さから見える丁寧さ。そして職務経歴との組み合わせから見える、キャリアの方向性です。

たとえば、海外部門への異動希望と直近のTOEIC受験がセットになっていれば、キャリアの意思が一本の線として伝わってきます。逆に、英語をまったく使わない職歴に8年前の700点だけがぽつんと置かれていると、そこから読み取れるものはほとんどない。点数は文脈の中で意味を持ちます。

英語をキャリアの中でどう位置づけるかは[英語はキャリアの武器になるか](/english/eigo-career-guide)で掘り下げています。資格全般の選び方は[転職に効く資格の選び方](/shikaku/tenshoku-shikaku-guide)もどうぞ。

## 面接で「TOEICについて」聞かれたときの答え方

履歴書に書いた以上、面接で触れられる可能性は当然あります。

**「なぜTOEICを受けたんですか」**——いちばん多い質問です。望ましいのは、業務やキャリアの文脈とつながった答え。「海外の情報を一次ソースで追えるようになりたかった」のように、目的から行動への順で語れると、学習の動機がそのまま仕事への姿勢として伝わります。

**「どうやって勉強しましたか」**——ここは時間管理能力を見られていると思ってください。「通勤時間と朝の30分を固定で充てた」のように、忙しい中で学習を仕組み化した話は、どんな職種でも評価されやすいポイントです。

**「実際に英語は使えますか」**——スコアと実務力のギャップを確かめる質問です。背伸びは禁物。「読み書きは抵抗がないが、会話はこれから」のように現在地を正直に伝えたうえで、続けている取り組みを添えるのが誠実で、結局いちばん信頼されます。

履歴書のスコアは、会話のきっかけにすぎません。その先のストーリーを準備しておけば、たった一行が面接での得点源に変わります。

## 今日、5分でできること

手元の履歴書を開いて、資格欄の一行を確認してみてください。正式名称になっているか。取得年月が入っているか。「合格」と書いていないか。

直すのに5分もかからないのに、ここを整えている応募者は驚くほど少ない。点数を上げるには200時間かかりますが、書き方を直すのは今日できます。まずはそちらからです。
